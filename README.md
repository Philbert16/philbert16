## 👤 About Me

Great frontend engineering isn't just about making things look good it's about making them feel effortless. That's the standard I hold myself to every time I write a line of code.
 
I'm a Frontend Software Engineer based in Ghana, focused on building responsive, accessible, and performant web applications using React, TypeScript, and modern JavaScript (ES6+). I care deeply about the details that separate a functional interface from a genuinely great one: clean component architecture, thoughtful state management, and UI that holds up across devices and edge cases.
 
My toolkit centers on React, TypeScript, JavaScript, HTML5, CSS3, and Tailwind CSS, backed by solid version control practices with Git and GitHub, and project workflows through Jira and ClickUp. I'm also an AWS Certified Cloud Practitioner, which has given me a working understanding of how frontend systems fit into broader cloud architecture, useful context when collaborating with backend and DevOps teams.
 
What drives me isn't just shipping features; it's understanding why they matter. I like working close to product decisions, asking questions about user experience, and pushing for solutions that are maintainable, not just functional. I'm equally comfortable diving into a legacy codebase to untangle technical debt as I am building something from a blank file.
 
I'm a continuous learner by habit, not obligation. I stay current with the React ecosystem, experiment with new tooling, and regularly revisit fundamentals to make sure my understanding isn't just surface-level. I believe the best engineers stay students of their craft.
 
Right now, I'm looking for opportunities as a Frontend Software Engineer, React Developer, or JavaScript Developer, ideally on a team building products at scale, where I can contribute technically while learning from engineers who push me to grow.
 
If you're hiring, building something interesting, or just want to talk shop about React, frontend architecture, or engineering career paths, I'd love to connect.
